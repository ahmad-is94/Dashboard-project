# 🚦 Traffic Collision Dashboard Project

## 📌 Overview
This project is an interactive data analysis dashboard built using Python, Pandas, Matplotlib, Seaborn, and Gradio.

## 📊 Features
- Interactive filters (date, category, age, search)
- KPI summary cards
- 10+ visualizations
- Heatmap, Violin, Scatter, Pie, etc.
- Clean UI dashboard

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Gradio

## 📂 Dataset
Traffic Collision Data from 2010 to Present

## 🚀 How to Run
```bash
pip install -r requirements.txt
python app.py
